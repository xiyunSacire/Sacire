PROJECT 01 / 04

Agent-Arena · 语言模型实时评测对战平台

FastAPI WebSocket LLM-as-a-Judge 分布式 C/S 架构 Python

提供可实时发布任务对本地模型进行综合评估的对战平台

针对本地大模型与微调 Agent 缺乏轻量、灵活、高频横向评测工具的痛点，构建了这套轻量级分布式任务发布与评测对战系统。采用服务端（Arena Server）与客户端（Student Client）双端架构，基于高并发 WebSocket 实现毫秒级任务广播、结果回传与大模型智能自动化评分。

  • 分布式任务广播与回传：服务端基于 FastAPI + WebSocket 实时向多客户端广播测试任务，支持高并发长连接状态维护与断线自动重连。
  • LLM-as-a-Judge 自动评分：内置大模型智能评估机制（LLMEvaluator），自动对比各端模型提交的答案，多维度生成评估打分与反馈。
  • 轻量解耦与极简接入：客户端提供优雅的 @client.on_task 装饰器，支持同步与异步逻辑，两行代码即可接入任何本地模型（vLLM / Ollama）参与同台竞技。

Python 3.10+ PyQt5 / Qt5 QMediaPlayer 双语歌词对齐 桌面悬浮 HUD LRC 制作工作台

具备毫秒级时间戳同步、双语对齐与独立穿透桌面歌词的本地化桌面音乐工作站

MusicPlayer 是一款基于 Python 与 PyQt5 开发的现代化 Windows 桌面音乐播放器。专为追求纯粹本地曲库与沉浸式歌词体验的音乐爱好者设计。深入针对 Windows Media Foundation (WMF) 底层音频跳转状态机与时钟漂移进行了针对性调优，提供毫秒级 LRC 逐行双语歌词对齐高亮、无边框置顶与鼠标穿透的桌面悬浮歌词、以及内置完整的 LRC 打点制作与时间轴微调工作台。

  • 高精度时间戳同步与跳转状态机：针对 Windows Media Foundation 底层异步 Seek 延迟与时钟累加漂移，自主设计跳转状态机（Seek State Machine）与快速位置回落算法，确保界面高亮歌词与底层音频毫秒级严格对齐。
  • 双语精准对齐与无边框桌面 HUD：支持同一时间戳下原文与译文的成对解析与高低层级排版；独立无边框桌面歌词悬浮窗支持自由拖拽、双击锁定鼠标穿透（Transparent For Mouse Events）与自定义字号色彩。
  • 内置一体化 LRC 制作微调工作台：集成打点标注、时间轴毫秒微调、逐句反复试听校准与翻译录入，并支持网易云等数据源多阶段智能抓取、合并与本地结构化缓存。
